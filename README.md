# Maison de Seoul VR

Simulation de vie dans un appartement coréen, version navigateur pour Meta Quest 3.

**Jouer :** ouvre <https://exteyz.github.io/maison-seoul-vr/> dans le navigateur du Quest, attends le chargement (environ 130 Mo), puis appuie sur **Entrer en VR**.

## Commandes

| Commande | Action |
| --- | --- |
| Stick gauche | Marcher (cliquer pour sprinter) |
| Stick droit | Tourner, bas/haut pour s'accroupir ou se relever |
| A | Sauter |
| Y ou B | Ouvrir le menu : réglages et phrases à dire |
| Grip | Saisir un objet ou une poignée |
| Gâchette | Plier l'index, valider dans le menu |
